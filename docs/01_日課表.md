# まなびば改修依頼：日課表

Oct 28, 2026 · @Nachi

## 全体方針：作り直しOK（11/2追加）

まなびばはこれまで何度か改修してきましたが、今回は**作り直し（スクラップ＆ビルド）でかまいません**。今までの画面や作りに合わせる必要はありません。この依頼書と、もう1本の依頼書（日課表／ワークドリル）を合わせて、**1つのアプリとして設計し直して**ください。目標は、母と子どもが考える順番どおりに、迷わず直感的に使えることです。

### 残すもの（いま使っている3つ）

- 暗記カード
- デジタルドリルのリンク集
- ポメチャット

この3つは、機能も**保存済みのデータもそのまま引き継いで**ください。作り直す前に、今のデータの保存先と形を確認してください。新しい作りにデータを移し終えてから、古いコードを消してください。それ以外の機能はほとんど使っていないので、なくしてかまいません（迷うものがあれば一覧にして保護者に聞いてください）。

### 子ども（香凜）の使い方の流れ

開いたらすぐ「今日やること」が出て、上から順にタップしていけば終わる流れにします。

1. ホーム＝今日の日課カード（日の種類・メイン教科・やること①〜⑥）
2. 行をタップすると、その作業の画面が直接開く。前日の×ならドリルの×の出し直し、暗記ならその日の教科に絞った暗記カード、スタサプならリンク、学校ワークならドリルの今日のページ。
3. 終わると自動でチェックが付いてホームに戻る。次にやる行が目立つ。
4. 全部終わると「今日はおわり」と出る。

- 画面の下にいつも同じボタンを並べる：ホーム／暗記カード／ドリル／リンク集／ポメチャット。
- 1つの画面でやることは1つだけ。文字は少なく、ボタンは大きくする（スマホ・タブレットで片手で使える大きさ）。
- 「次にどこを押すか」で迷わせない。戻るボタンはいつも同じ場所に置く。
- 時間は目安として小さく出すだけにする。守るのは順番。

### 保護者（母）の使い方の流れ

- 保護者用の機能は✏️保護者モードの中だけにまとめ、子どもの画面には出さない。
- 保護者モードを開いた最初の画面に置くもの：①今日と今週の結果（終わった行、×の数と一覧）②カレンダー（日の種類・テスト日）③ドリルの取り込み（ファイルを選ぶだけ）④「この問題おかしい」の報告一覧
- 母の操作は「見る」「タップで切り替える」「ファイルを選ぶ」の3つにしぼる。文字を打つ場面はできるだけなくす。

### 共通

- 1つのHTMLファイルのままにする。データは端末の中（IndexedDB）に保存する。
- 保護者モードに「バックアップを書き出す／読み込む」ボタンを付ける。

## 背景と目的

2学期中間テストの分析（[定期テスト傾向分析と学習設計](https://claude.ai/artifact/4T1rbwHfhzyednx4HJzjdV)）から、テストの大半は学校ワークと同じ問題・同じ型から出ることがわかりました。一方で本人は毎日「今日何すればいい？」と指示待ちです。

そこで、まなびばを開けば「今日やること」が順に並んでいる状態を作ります。学校ワークを1問ずつ解く機能は別の依頼（[まなびば改修依頼：ワークドリル](https://claude.ai/artifact/LxsjmnHPZr5Ctd8oF9XLCC)）で進めます。**日課表はドリルがなくても単独で使えるように作ってください。**

## 依頼内容：「今日の日課」カード

既存のテスト計画機能に、「今日の日課」カードを追加してください。

### ふだんの表示（本人用）

- 開くと、今日の「日の種類」と「メイン教科」、やることが順に並ぶ。各行は「□タスク名 ⏱」だけ。
- 上から順にチェックする。時間は目安で、守るのは順番（以前、時間割方式は続かなかったため）。
- 各行には「何を使うか」を一言そえる（例：「学校ワーク 数学 p45〜」「スタサプ 数学 1本」）。
- ワークドリルができたら、「学校ワーク」「×の解き直し」の行をタップするとドリルが開くようにする。それまではチェックだけでよい。

### 日の種類（11/2 更新）

| 種類 | 条件 | やること（順番） |
| --- | --- | --- |
| A日 | 夜練・試合の日 | ①帰宅後すぐ：前日の×（目安15分） ②すきま時間：暗記（英単語か漢字） |
| B日 | それ以外（約2時間） | ①帰宅後すぐ：前日の×（目安15分） ②暗記15分 ③スタサプ「今週のミッション」30分 ④学校ワーク40分 ⑤直し20分（答えを見て理解する） ⑥休憩・予備15分 |
| 暗記のみ | 大会など | 暗記15分 |

②〜⑤はすべてその日の**メイン教科**でそろえます。暗記の中身は、国語＝漢字、英語＝英単語、社会＝社会、理科＝理科、数学＝特になければ英単語です。

### 前日の×のルール（ためない）

- 目安は15分。終わらなければ続けてよいが、そのぶん④学校ワークを短くする。×の時間は最大30分。
- それでも残った×は、部活OFFの日か週末にまとめて片づける。
- 2回続けて○になった問題は卒業（ドリルと同じルール）。
- 新しいページより×を先にやる。

### メイン教科の決め方

- B日ごとに **国語→数学→社会→理科→英語→数学** の6つで回す（数学は最優先なので2回）。曜日ではなく順番で進める。
- A日や「暗記のみ」の日は順番を進めない。
- 小テストがある日は、その教科と入れ替えてよい。飛ばされた教科は消さずに次のB日へ回す。

### テスト前（テスト日から逆算して自動で切り替え）

テスト日を入れると、テスト前日に終わるように3つの期間へ自動で切り替わります。日数の初期値は5日・5日・3日で、保護者が変えられます。毎日の①前日の×と②暗記はそのまま続けます。③スタサプはテスト対策の講座に替えます。④⑤は下の中身に替えます。

| 期間 | 中身 |
| --- | --- |
| 1期（5日） | 最初に各教科の**まとめ問題を「検査」として解く** → ×の出た単元から順に、紙のワーク1回目を見ずに解く。必ず入れるページ：理科の仕上げページ（キホンの入試〜単元の完成）、数学の1学期範囲。 |
| 2期（5日） | 間違えたところの1回目の解き直し。 |
| 3期（3日） | 間違えたところの2回目の解き直し → 見ずに解けるまで仕上げる。まとめ問題の2回目。模擬テストは初めて見る問題でやる（攻略本の予想問題・30分100点）。余裕があれば教科書の章末問題・アウトプット問題集など。社会は「ちがいに注意」の対を声に出して言う。 |

紙のワークの位置づけ：ふだんはアプリ（ワークドリル）で定着させ、テスト前は紙のワークで「見ないで解ける」ことを確かめます。紙で×だった問題は「前日の×」に回します。

### 保護者の操作（✏️編集モード）

- カレンダーで日ごとに種類（A／B／暗記のみ／休み）をタップで切り替える。初期値はB。
- その日のメイン教科を手で変えられる。
- テスト日を入れると、テスト前の1期・2期・3期の切り替えが自動でかかる（日数は5・5・3日を初期値に変更可）。
- 既存の「毎日の暗記行」は、日課の①としてそのまま使う。

### 11月の入力例

夜練：11/11、11/18、11/26（10月は10/22、10/28、10/29）。部活：11/1、11/2、11/3、11/7、11/14、11/15、11/28。県大会11/4・5は「暗記のみ」。テスト初日は仮に11/24（日程が決まったら差し替え）。
