# まなびば改修依頼：ワークドリル

Oct 28, 2026 · @Nachi

## 全体方針：作り直しOK（11/2追加）

まなびばはこれまで何度か改修してきましたが、今回は**作り直し（スクラップ＆ビルド）でかまいません**。今までの画面や作りに合わせる必要はありません。この依頼書と、もう1本の依頼書（日課表／ワークドリル）を合わせて、**1つのアプリとして設計し直して**ください。目標は、母と子どもが考える順番どおりに、迷わず直感的に使えることです。

### 残すもの（いま使っている3つ）

- 暗記カード
- デジタルドリルのリンク集
- ポメチャット

この3つは、機能も**保存済みのデータもそのまま引き継いで**ください。作り直す前に、今のデータの保存先と形を確認してください。新しい作りにデータを移し終えてから、古いコードを消してください。それ以外の機能はほとんど使っていないので、なくしてかまいません（迷うものがあれば一覧にして保護者に聞いてください）。

### 子ども（香凜）の使い方の流れ

開いたらすぐ「今日やること」が出て、上から順にタップしていけば終わる流れにします。

1. ホーム＝今日の日課カード（日の種類・メイン教科・やること①〜⑥）
2. 行をタップすると、その作業の画面が直接開く。前日の×ならドリルの×の出し直し、暗記ならその日の教科に絞った暗記カード、スタサプならリンク、学校ワークならドリルの今日のページ。
3. 終わると自動でチェックが付いてホームに戻る。次にやる行が目立つ。
4. 全部終わると「今日はおわり」と出る。

- 画面の下にいつも同じボタンを並べる：ホーム／暗記カード／ドリル／リンク集／ポメチャット。
- 1つの画面でやることは1つだけ。文字は少なく、ボタンは大きくする（スマホ・タブレットで片手で使える大きさ）。
- 「次にどこを押すか」で迷わせない。戻るボタンはいつも同じ場所に置く。
- 時間は目安として小さく出すだけにする。守るのは順番。

### 保護者（母）の使い方の流れ

- 保護者用の機能は✏️保護者モードの中だけにまとめ、子どもの画面には出さない。
- 保護者モードを開いた最初の画面に置くもの：①今日と今週の結果（終わった行、×の数と一覧）②カレンダー（日の種類・テスト日）③ドリルの取り込み（ファイルを選ぶだけ）④「この問題おかしい」の報告一覧
- 母の操作は「見る」「タップで切り替える」「ファイルを選ぶ」の3つにしぼる。文字を打つ場面はできるだけなくす。

### 共通

- 1つのHTMLファイルのままにする。データは端末の中（IndexedDB）に保存する。
- 保護者モードに「バックアップを書き出す／読み込む」ボタンを付ける。

## 背景と目的

2学期中間テスト5教科の分析（[定期テスト傾向分析と学習設計](https://claude.ai/artifact/4T1rbwHfhzyednx4HJzjdV)）から、次の3つがわかりました。

1. テストは学校ワークと同じ問題・同じ型から大半が出る（国語約86点、英語約76点、数学約72点）。
2. 失点の多くは「解いていないページ」「甘い丸つけ」「×を見ずに解き直していない」から来ている。
3. 本人は毎日「今日何すればいい？」と指示待ち。また、ワークの持ち帰り忘れや、ページをめくる・答えを探す・×を記録する・正誤を判定する作業の負荷が高い。

そこで、学校ワークを1問ずつまなびばで解けるようにします。答え合わせと×の記録・出し直しはアプリがやります。以前ワークを丸ごと問題にして読み込ませたとき、本人が「良かった」と言っています。「今日やること」を並べる日課表は別の依頼（[まなびば改修依頼：日課表](https://claude.ai/artifact/UQyLXyDJ6k7bJUdzPfEJHb)）で先に進めます。

## 基本方針：ワークの形を変えない

**問題は書き直さず、ワークの写真をそのまま出します。図の問題も文章の問題も、ページ順に1つの流れで出します。**

- 理由①：1学期中間では、文章の問題ばかり繰り返し、図の入った問題をほとんどやらずに大きく失点した。問題を「図」「文章」「紙でやる」などに分けると管理が煩雑になり、図の問題が取り残される。
- 理由②：テストはワークと同じ問題・同じ見た目で出る。ワークの問題をそのままの形でやることに意味がある。
- アプリが変えるのは「答え方」と「答え合わせ」だけ。ページめくり、答え探し、×の記録、出し直しをアプリが引き受ける。
- 「紙でやる問題」などの別リストは作らない。作図や記述も同じ流れの中で、ノートに書いて自分で判定する。
- **保護者の手間を最小にする。** 前回は図を切り抜いて問題と紐付ける作業に手間がかかり、しかも貼り付けがずれて解けない問題が多く出た。今回は**切り抜き・紐付けをやめ、ページの写真を丸ごと使う**。保護者は「撮ってClaudeに送る」「1ファイル取り込む」の2つだけ。

## 依頼内容

学校ワークを問題データにして取り込み、1問ずつ解ける画面を作ってください。**本人がやるのは「解く」だけにし、ページめくり・答え探し・×の記録・出し直しはアプリがやります。**

### 解く画面

- 1画面1大問。上半分に**ワークのページ写真を丸ごと**表示し、今の大問の位置（`region`）に自動でズーム・枠線表示する。
- 指でピンチ・ドラッグすればページ全体が見える。「ページ全体」ボタンも置く。**写真を切っていないので、位置が多少ずれても図や前の問題は必ず見える。**
- 下半分に、その大問の小問の解答欄を (1)(2)(3)… と並べ、解答欄だけがスクロールする。
- 「次へ」で次の大問へ。同じページなら写真はそのままでズーム位置だけ動く（ページをめくる感覚）。
- 上に「数学｜方程式　ワークp45 ⓷　3/12」のように、今どこかを小さく表示する。
- 「この問題おかしい」ボタンを置く（位置ずれ・正解が違うなど）。押すと保護者画面の「報告」にたまり、その問題は×にしない。保護者は報告をまとめてClaudeに渡すだけで直せる。

### 形式ごとの答え方と判定

| 形式 | 答え方 | 判定 |
| --- | --- | --- |
| 選択・記号 | タップ | 自動 |
| 並べかえ（英語） | 語をタップして並べたあと、**完成した文を自分で入力** | 自動（入力した文で判定） |
| 語句・漢字・数値・英文 | 入力 | 自動。全角半角と空白だけはゆるめる。**英語のコンマ・「?」・大文字、数学の符号と単位は判定に含める** |
| 式・記述・作図 | ノートに書く→「答えを見る」 | 解答ページの写真（該当位置にズーム）と採点基準を表示し、本人が○／×をタップ。採点基準はチェックボックスにし、全部☑でないと○を押せない |

- **不正解のときは、自分の答えと正解を上下に並べ、違う文字を色で示す。** 「緊強」と「緊張」、「please」の前のコンマのような見落としを、本人が自分で気づけるようにするため。
- 自動判定で×になったが本当は正解の場合（別解など）は、保護者だけが○に直せる。

### ×の記録と出し直し

- ×は自動で「×リスト」に入る。
- **同じ日には出し直さない。** 答えを見た直後に解くと「見て直した」のと同じになるため。翌日以降の「×の解き直し」で出す。
- 2回続けて○なら×リストから卒業。
- 既存の「理科 2回以上×で暗記カード化」と同じ考えで、3回以上×の問題は「苦手」印をつけて保護者画面に出す。
- ×は小問ごとに記録する。解き直しのときもページの写真をその大問にズームして出し、×だった小問の解答欄だけを開ける。

### 日課表とのつながり

- 「学校ワーク」の行：その日の教科で、まだ解いていない問題をページ順に出す。保護者が「授業はこのページまで進んだ」を教科ごとに設定し、そこより先は出さない。
- 「×の解き直し」の行：前日以前の×を、教科をまたいで古い順に出す。
- テスト2週間前からは、テスト範囲で未着手の問題を優先して出す。

### 保護者画面

- 教科ごとに「全問題／解いた／×が残っている」の数と、テスト範囲の未着手の数。
- 「苦手」印の問題の一覧。

### 紙のワーク（提出物）との役割分担

- **ドリル（アプリ）＝ふだんの定着用。** 授業が進んだところから解き、×を出し直して覚える。
- **紙のワーク＝テスト期間の確認用。** テスト2週間前から紙のワークで改めて解き、「見ないで解ける」ことを確かめる。紙に書くことで提出物も仕上がる（書き写し自体は本人の負担にならない）。
- 紙で×だった問題は、保護者が問題番号を選んでドリルの×リストに入れられるようにする（例：「数学 p45 3(2)」をタップで×に）。

## ワークのデータ化の流れ

1. **撮影して送る（保護者、数分）**：ワークを持ち帰った日に、次の範囲の問題ページと解答ページを撮る。上から真っすぐ、1ページ1枚。順番やファイル名は気にしない。Claudeのスレッドにまとめて送る。
2. **変換（Claude）**：写真を読み、ページ番号を判定し、問題ページと解答ページを自動で対応づける。大問ごとの位置（`region`）と、各小問の正解・答え方・採点基準を作る。写真は傾きを直して縮小するだけで切らない。**写真も正解も全部入った1ファイル**（`.json`）にして渡す。読めない・解答ページが足りない場合は、そのページだけ撮り直しを頼む。
3. **取り込む（保護者、1操作）**：まなびばの「ワークを取り込む」でその1ファイルを選ぶだけ。同じページを取り込み直したら上書きし、そのページの学習記録（○×）は問題idで引き継ぐ。

写真は1枚200KB前後（長辺1400px程度のJPEG）を想定。数十ページ分で数MBになり localStorage では入らないため、**IndexedDB に保存**してください。

### 問題データの形式（案）

```json
{
  "workbook": "数学ワーク",
  "subject": "math",
  "pages": [
    {
      "page": 52,
      "image": "data:image/jpeg;base64,...",
      "answerPage": 12,
      "answerImage": "data:image/jpeg;base64,...",
      "blocks": [
        {
          "bid": "math-w52-2",
          "unit": "文字式の利用",
          "no": "2",
          "region": {"x": 0.0, "y": 0.42, "w": 1.0, "h": 0.33},
          "answerRegion": {"x": 0.5, "y": 0.1, "w": 0.5, "h": 0.15},
          "items": [
            {
              "id": "math-w52-2-1",
              "no": "(1)",
              "type": "number",
              "answer": "20-x",
              "alt": ["-x+20"],
              "exp": "縦＋横＝20だから 横＝20-x"
            },
            {
              "id": "math-w52-2-2",
              "no": "(2)",
              "type": "self",
              "answer": "解答ページ参照",
              "rubric": ["式を書いている", "答えに単位 cm² がある"]
            }
          ]
        }
      ]
    }
  ]
}
```

- `pages`：ワークの1ページ。`image` はページ写真丸ごと（切らない）、`answerImage` は対応する解答ページの写真。画像はファイル内に埋め込むので、取り込みは1ファイルで完結する
- `blocks`：大問。`region` はページ写真の中でその大問がある範囲（写真の幅・高さに対する0〜1の割合）。表示でズームする場所を示すだけで、写真は切らない。`answerRegion` も同様
- `items`：その大問の小問。問題文は持たず、正解と答え方だけを持つ
- `type`：choice（選択。`choices` に選択肢の記号）／order（並べかえ）／word（語句・漢字）／number（数値・式の答え）／sentence（英文）／self（途中式・記述・作図＝ノートに書いて自己判定）
- `alt`：正解として認める別の書き方
- `rubric`：self のときの採点基準。全部☑でないと○を押せない
- `exp`：解説（解答編にあれば）

### 確認したいこと（保護者）

1. 最初にデータ化する教科（案：数学と英語。図の問題も含めて全部）。
2. 紙で×だった問題をドリルに戻す操作は、保護者がやるか本人がやるか。
